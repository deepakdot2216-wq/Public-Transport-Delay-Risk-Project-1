# Public Transport Delay Risk Prediction System

## About the Project

This is my college project, in which I am working on predicting the risk of bus delays using Machine Learning. I am using historical bus delay data to understand delay patterns and build a model that can predict delay risk based on the available information.

I have collected the dataset, cleaned it, and trained a Machine Learning model. Now I am working on the remaining parts of the project, including model evaluation, the Streamlit application, and testing.

## Dataset

I am using the Bus Breakdown and Delays dataset from NYC Open Data.

Dataset link: https://data.cityofnewyork.us/Transportation/Bus-Breakdown-and-Delays/ez4e-fazm

The dataset contains information about bus delays, routes, reasons for delays, boroughs, and the number of students on the bus.
